## Java Aspects selective texture overlay

Java Edition 26.3 asset provenance and existing pack licensing are documented above. This 9.0.6 stability build uses the Java Aspects 6.5.0 Default Textures item image set and merged item texture registry only. Block, entity, GUI, and other broad texture replacements are omitted while isolating the Minecraft world-join crash. Java Aspects license and credits are preserved in third_party. The Java Aspects license permits personal modification and prohibits redistribution without explicit permission from AgentMindStorm.

## HUD removal

Version 9.0.7 removes the resource-pack UI overrides, custom HUD textures, subtitle-driven HUD script, and personal HUD settings menu. The standard Bedrock HUD is used. PvP, offhand, and Java Aspects item textures remain.
