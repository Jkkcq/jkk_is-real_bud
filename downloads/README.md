# Minecraft Java Addon Downloads

Save these on your laptop, then open the `.mcaddon` files (or unzip the zip first).

| File | What |
|------|------|
| [Minecraft-Java-Addons.zip](./Minecraft-Java-Addons.zip) | Both packs + install notes |
| [JavaPvP-10.3.53.mcaddon](./JavaPvP-10.3.53.mcaddon) | Java PvP BP+RP |
| [JavaRedstone-1.22.3.mcaddon](./JavaRedstone-1.22.3.mcaddon) | Java Redstone BP+RP |

## Install
1. Download / unzip
2. Double-click or open each `.mcaddon` with Minecraft Bedrock
3. Enable both Behavior + Resource packs in the world
4. Turn on Beta APIs / scripting experiments if prompted
